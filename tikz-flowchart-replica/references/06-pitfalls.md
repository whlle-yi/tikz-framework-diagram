# 踩坑清单

按"症状 → 原因 → 修法"排。出问题先对照这里。

## 单位与尺寸

**1. 整幅图放大 2.54 倍**
用了 `x=0.0352778cm`（那是 1/72 英寸）。应为 `x=0.0138889cm`（1/72 cm）。

**2. 文字全部飞出框外，行距明显偏大**
把像素值直接填进了 `\fontsize{}{}` 的第二个参数。像素要乘 0.3937 才是 pt。
反例：`\fontsize{8.2}{27.9}` 想表达 27.9px 行距，实际是 27.9pt = 71px。

**3. 空心箭头"只剩个头"**
总高小于头长。设 `总高 = 16、头长 = 13`，箭轴只剩 3px，视觉上就是个倒三角。
约束：`总高 ≥ 头长 + 8`。这类小连接件的高度必须单独量，不能沿用其他箭头。

**4. 虚线看起来像描边**
dash pattern 密度不对。原图 4px 实 / 3px 空 → `on 1.6pt off 1.2pt`（×0.3937）。

## 线条与端点

**5. 框被一条斜线穿过内部**
分段画路径时末段加了 `-- cycle`。`cycle` 回到的是**当前子路径起点**，不是整条 path 的起点。
标签框"左边+顶边 / 箭头 / 右边+底边"三段式，末段不能 cycle。

**6. 支架有一根竖线悬空**
横干端点没落在子节点中心线上。例：下垂线在 x=449 与 772，横干却画到 762，
右边那根竖线就落不到横干上。横干必须用 `首中心 → 末中心`。

**7. 整条虚线容器漏画**
扫描时覆盖率阈值设成 0.7，而虚线覆盖率只有 50~60%，被整条过滤掉。
虚线要单独用 0.30–0.80 再扫一遍。漏掉的往往是"外围还有几个并排单元"这类结构。

**8. 相邻框的边粘成一条粗线**
两个框各有自己的边框，间距 6~10px。不要合并成一个框，照原样各画一个。

## 中文排版

**9. 多行文字最后一行溢出框外**
xeCJK 把 CJK 行距放大约 10%，行数越多累积越明显。
改成逐行独立 node 定位，行距用原图实测 pitch。

**10. 竖排文字与框不贴合**
用了统一 pitch。原图每个标签的 pitch 常常不同（19 / 20 / 25 / 31 都出现过），
必须逐个量：量首字中心、量相邻字中心差。

**11. `分支1` 中间多了个空格**
xeCJK 的 CJK-Latin 自动间距。加 `\xeCJKsetup{CJKecglue={}}`。

**12. `\bfseries` 报 Undefined control sequence**
两个原因：① 没指定 BoldFont；② 汉字紧跟在 `\bfseries` 后面被当成控制序列名的一部分
（xeCJK 下汉字 catcode 为 11）。写法要加空格：`{\bfseries 研究步骤}`。

## 流程与工具

**13. 覆盖 PDF 报 `Error 1 (driver return code)` / `PermissionError`**
目标 PDF 正被预览面板打开。用 `xelatex -jobname=tmp` 输出新名，再改名；
或另存一个文件名交付，并在说明里注明哪个是最新。

**14. 改了 `.tex` 下次生成又被覆盖**
工作流是"改生成器 → 重新生成 → 编译"。所有修改都落在 `.py` 里，`.tex` 是产物。

**15. 目测调参越调越乱**
一旦开始靠目测改坐标，就会陷入"改了 A 坏了 B"。回到 `measure.py` 重新量，
用叠色图判定，不要靠眼睛估。

- [ ] 每个空心箭头的总高 ≥ 头长 + 8
- [ ] 没有文字越出框线（逐个放大看）
