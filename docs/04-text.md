# 中文文字排版

这类图里文字占的分量比线还重，也是"像不像"的主要差异来源。

## 1. 字号 = 字宽

汉字的**字宽等于字号**（1em）。所以最可靠的定号方法是量墨迹宽度：

```
字宽(px) = 墨迹宽度 ÷ 字数
字号(pt) = 字宽(px) × 0.3937
```

例：`工况实测数据库` 7 字，墨迹 148px → 21.1px/字 → 8.3pt。

墨迹高度约为字号的 0.86 倍，可用来交叉验证，但不如宽度可靠（受笔画影响）。

## 2. 多行文本：不要依赖 `\\` 和 baselineskip

**xeCJK 会把 CJK 行距再放大 ~10%**。两行看不出来，八到十行会累积出半行到一行的溢出，
表现为"最后一行跑到框外面"。

可靠做法：**每行一个独立 node，坐标自己算**。

```python
def mlines(cx,cy,lines,fs=8.3,pitch=30):
    n=len(lines)
    for i,t in enumerate(lines):
        y=cy+(i-(n-1)/2)*pitch          # pitch = 原图实测行距(px)
        node(f"font=\\fontsize{{{fs}}}{{10}}\\selectfont", (cx,y), t)
```

`pitch` 一律从原图量（相邻两行墨迹中心的差值），不要用 `1.2×字号` 估。

## 3. 中文竖排

两种不同版式，必须分辨清楚：

| 版式 | 判断依据 | 排法 |
|---|---|---|
| **单字竖排** | 墨迹宽 ≈ 1 字宽、高 ≈ N 字宽 | 每行 1 字，逐字独立 node |
| **横排窄栏** | 墨迹宽 ≈ 3 字宽、高 ≈ M 行 | 每行 3 字（或按实测），横向换行 |

判断方法：量墨迹包围盒的宽高比。宽 17px / 高 122px → 单字竖排；
宽 52px / 高 79px → 每行 3 字、共 4 行。

竖排也必须逐字定位：

```python
def chars_at(cx, y_first, pitch, text):
    for i,ch in enumerate(text):
        node(font, (cx, y_first+pitch*i), ch)
```

`y_first` 由实测首字的**中心**给出，`pitch` 由实测相邻字中心差给出。
不同标签的 pitch 往往不一样（原图是手工拉的），**逐个量，不要套统一公式**。

实测例：10 字标签 pitch 25.7，6 字标签 20.2 / 30.8，5 字 19，4 字 25.3——同一张图里各不相同。

## 4. 汉字与数字/字母的间距

默认 xeCJK 会在 `分支1` 之间插入空隙，看起来像多了个空格。关掉：

```latex
\xeCJKsetup{CJKecglue={}}          % 或 {\hskip 0pt}
```

## 5. 粗体

- 只有标题、标签框、结论条用粗体；正文框一律常规
- 必须显式指定 BoldFont，否则报 `Undefined control sequence`
- 判断原图是否粗体：看笔画粗细与字号的比例，粗体约为常规的 1.3 倍

## 6. 换行必须照抄原图

包括原图的**错误换行**。例如原图把「记录XXXXXXXX分布」折成 `记录 / XXXXXXXX分 / 布`，
照抄，不要自作聪明改成整齐的三行——复刻的第一目标是"和原图一致"。

遇到原图的错别字（如「归一化归一处理」「可信约束设」）也照抄，
在交付说明里指出，让用户自己决定改不改。

## 7. 长标题放不下时

优先级：① 缩小字号 ② 拉宽框 ③ 手动断行。
不要依赖自动换行——断点位置不可控，会和原图差一个字。

正文框内的多行文字同理：**行内容手动写死**，让生成器逐行渲染。

## 8. 对齐

- 框内文字一律水平居中、垂直居中
- 竖排文字在框内水平居中
- 表格类（框内分格）每格独立居中，不要用 tabular（列宽难控）
