# 工作流总览

把一个位图流程图变成对齐的 TikZ 矢量图，分 7 步。每步的详细方法见对应文档。

```
位图 ──① 量取几何──▶ 坐标表 ──② 工程配置──▶ LaTeX 骨架
                                             │
                                    ③ 拆解图元（形状/文字）
                                             ▼
                                    ④ 写生成器（Python）
                                             ▼
                                    ⑤ 编译 ──▶ PDF
                                             ▼
                              ⑥ 叠色比对 ◀──┐ 迭代
                                    │        │
                                    └─有差异──┘
                                             ▼
                                    ⑦ 交付 .tex + .pdf
```

## ① 量取几何 → [01-measure.md](01-measure.md)

先分清"图"和"页面"：截图底色、页面留白、扫描阴影不属于图，一律不画；穿过图内部结构的虚线框、分组框属于图，要画。

然后用三类扫描把结构量化：

| 扫描 | 得到什么 |
|---|---|
| 长线段 | 虚线容器、每一排框的上下边、树形支架横干 |
| 覆盖率 | 一排方框的左右边界（逐列占比 >0.75 的列即竖边） |
| 墨迹包围盒 | 文字宽高 → 反推字号 |

配 `scripts/measure.py`，另有两个应急工具：`row/col` 逐行游程（读小构件如箭头）、`art` ASCII 结构图（快速看懂树形）。

产出：一份像素坐标表，后续所有工作只认这一份。

## ② 工程配置 → [02-tex-setup.md](02-tex-setup.md)

`standalone` + `xeCJK` + 中文字体，坐标系 `x=0.0138889cm, y=-0.0138889cm`。

**这一步最容易出错**：绘图坐标用单位（1/72cm），字体尺寸用 pt（1/72in），两者差 2.54 倍。
像素 → pt 要乘 0.3937。把像素值直接填进 `\fontsize{}{}` 会让行距放大 2.54 倍。

## ③ 拆解图元 → [03-shapes.md](03-shapes.md) · [04-text.md](04-text.md)

把图拆成有限的几种图元，逐个实现：

- 几何：矩形、圆角、胶囊、虚线/点线容器、圆柱、立体卡片、空心块箭头、双向箭头、树形支架、扇形发散
- 文字：单行居中、多行（逐行定位）、中文竖排（逐字定位）、共边标签框

拆得越干净，第④步越省事。同一形状出现两次以上就写成函数。

## ④ 写生成器

复制 `scripts/scaffold.py`，把坐标表填进去。原则：

- 数据（坐标、文字）与渲染（函数）分离
- 每个图元一个函数调用，一眼能对上原图
- 所有尺寸从坐标表取，不在函数里写魔法数字

## ⑤ 编译

```bash
python gen.py && xelatex -interaction=nonstopmode -halt-on-error fig.tex
```

只改 `gen.py`，不改 `fig.tex`（会被覆盖）。

## ⑥ 叠色比对 → [05-verify.md](05-verify.md)

```
Red = 只有我的     Blue = 只有原图     Black = 重合
```

渲染 dpi 取 183（1 单位 ≈ 1 像素），用 `scripts/overlay.py` 一条命令出图。
先看整幅找结构性缺失，再放大到 1:1 看箭头、支架端点、竖排文字。

至少迭代 3 轮。用户说"不对"时不要重画，先叠色定位。

## ⑦ 交付

`.tex` + `.pdf` + 预览图。说明：

- 仍存在的偏差（通常是字体亚像素差）
- 原图本身的错漏（错别字、错误的自动换行）——照抄，但要告诉对方
