# 07 附：与既有图对齐（可选）

**默认不需要**。正常流程是从内容出发按风格画图。
只有当用户给了一张位图并要求"和这张图一模一样"时，才用这套方法。

核心思路：不靠目测，把位图量成坐标表，再逐轮叠色比对。

## 1. 量取几何

坐标系统一取**绘图区左上角**为 (0,0)，向右 +x、向下 +y。所有测量值原样记录，不做换算。

### 1.1 三类扫描

| 扫描 | 命令 | 得到 |
|---|---|---|
| 长线段 | `measure.py hlines / vlines` | 虚线容器、每排框的上下边、树形支架横干 |
| 覆盖率 | `measure.py edges` | 一排方框的左右边界（逐列占比 >0.75 即竖边） |
| 墨迹包围盒 | `measure.py ink --chars N` | 字宽 → 反推字号 |

```bash
python scripts/measure.py edges img.jpg --y0 215 --y1 260      # 一排框的左右边界
python scripts/measure.py ink   img.jpg --x0 330 --y0 75 --x1 450 --y1 110 --chars 7
```

`edges` 直接输出 `313-427, 434-548…` 这样成对的边界，`ink` 顺便给出 `font ~8.3pt`。

### 1.2 虚线要单独扫
虚线覆盖率只有 50–60%，用 0.75 的阈值会**整条漏掉**。单独扫一遍 0.30–0.80：

```bash
python scripts/measure.py dashed img.jpg
# dashed col x=142 coverage=0.69
# dashed col x=281 coverage=0.57   ← 说明这里有并排的两个单元
```

### 1.3 小构件逐行扫
箭头、支架端点这类几像素的东西，用单行/单列游程读：

```bash
python scripts/measure.py row img.jpg --y 380 --x0 500 --x1 700
# [(585,587), (623,624)]        ← 箭轴的两条竖边
# [(566,587), (623,644)]        ← 箭头底边
```

### 1.4 看不清结构时用 ASCII 图
```bash
python scripts/measure.py art img.jpg --x0 300 --y0 118 --x1 920 --y1 250 --sx 5 --sy 4
```
降采样成字符画，快速判断树形 / 支架 / 箭头的连接关系（只看结构，别读文字）。

### 1.5 易混情况

| 现象 | 原因 | 处理 |
|---|---|---|
| 一排框边界数是奇数 | 某条边被文字或箭头切断 | 换一个 y 区间重扫 |
| 出现相距 8–10 px 的两条平行线 | 相邻两框各有边（框间有缝） | 按两个框处理 |
| 折叠卡片有两组边 | 正面 vs 顶面后边 | 差值即 3D 偏移 `(dx,dy)` |
| 清单里出现 500–600 px 的横线 | 可能是树形支架横干 | 结合上下短竖线判断 |

## 2. 叠色比对

### 2.1 1:1 渲染
绘图单位 1 unit = 1/72 cm，要让它等于 1 px：

```
dpi = 72 / 2.54 × 72 ≈ 182.88   → 取 183（误差 <1 px / 1300 px）
```

`standalone` 的 `border=6pt` = 15.24 单位，脚本会按 `--border` 自动扣掉。

### 2.2 一条命令

```bash
python -c "import pymupdf; pymupdf.open('fig.pdf')[0].get_pixmap(dpi=183).save('out.png')"
python scripts/overlay.py img.jpg out.png --orig 141,38,1076,1417 --out overlay.png --diff
```

**颜色语义：红 = 我的，蓝 = 原图，黑 = 重合。**
搞反会把"我漏画"看成"我多画"。

### 2.3 判读表

| 症状 | 结论 | 修法 |
|---|---|---|
| 整块只有红或只有蓝 | 元素缺失/多画 | 回坐标表核对 |
| 一整条横线只有蓝 | 虚线容器漏画 | 用 0.30–0.80 重扫 |
| 竖线与横干差 10 px | 支架端点抄错 | 端点落在子节点中心线 |
| 框线整体偏 5–10 px | 某个边界抄错 | 重扫该排 `edges` |
| 文字错位 2–5 px | 行距/首字位置 | 改逐字逐行定位 |
| 文字错位 10 px+ | 字号换算错（px 当 pt 用） | 见 `05-tex-setup.md` |
| 红蓝交替的虚线 | 虚线相位不同 | 忽略 |
| 边缘毛刺 | 字体渲染差异 | 忽略 |

一般迭代 3–5 轮收敛。整图至少完整比对 2 轮。
局部（箭头、支架端点、竖排文字）要放大到 1:1 再看。

## 3. 什么时候该放弃对齐

- 原图本身有错（错别字、错误换行）——按原样还是改正，先问用户
- 原图是扫描件、透视畸变——先做去畸变，否则对齐没有意义
- 原图分辨率不足 150 dpi——文字边界不清，量出来的字号会偏大

这几种情况下，直接按 `01-style.md` 的风格重画，比"对齐"更快也更好。
