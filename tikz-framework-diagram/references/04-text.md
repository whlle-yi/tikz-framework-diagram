# 04 文字排版

这类图里文字占的分量比线还重。字号乱一级、行距差 2px，整张图就"不像论文里的图"。

## 1. 字号只取 4 级

| 级别 | 字号 | 用途 |
|---|---|---|
| L1 | 11–12 pt 粗 | 图的主标题条 |
| L2 | 8.3 pt 粗 | 区块标题、左侧竖排标签、结论条 |
| L3 | 8.3 pt 常规 | 正文框（最常用） |
| L4 | 6.5–6.9 pt | 极密图的正文 |

**字号 = 汉字字宽**（1 em）。想反推字体大小，量一排字的墨迹宽度除以字数即可：

```
字号(pt) = 墨迹宽度(px) ÷ 字数 × 0.3937
```

宽度比高度可靠——汉字墨迹高度只有字号的 0.86 倍左右，且随笔画多少浮动。

## 2. 多行文本：逐行定位，不要靠 `\\`

**xeCJK 会把 CJK 行距再放大约 10%**。两行看不出来，八到十行会累积出半行到一行的溢出，
表现为"最后一行跑到框外面"——这是最常见的返工原因。

可靠做法：每行一个 node，坐标自己算。

```python
def mlines(cx, cy, lines, fs=8.3, pitch=30):
    n = len(lines)
    for i, t in enumerate(lines):
        y = cy + (i - (n - 1) / 2) * pitch      # 行距固定 30
        node(f"font=\\fontsize{{{fs}}}{{10}}\\selectfont", (cx, y), t)
```

行距固定 **30 px**（8.3 pt × 1.4），全文统一。不要按行数压缩——行数多就加高框。

## 3. 竖排 vs 横排窄栏

两种版式，别混用：

| 版式 | 外观 | 适用 |
|---|---|---|
| **单字竖排** | 宽 1 字、高 N 字 | 左侧标签框（`数据源头归集与预处理`） |
| **横排窄栏** | 宽 3 字、高 M 行 | 窄框里的正文（`研究样 / 点选择 / 与实地 / 测量`） |

判断依据看框的宽高比：宽约 1 字 → 竖排；宽约 3 字 → 窄栏横排。

竖排也必须逐字定位：

```python
def chars_at(cx, y_first, pitch, text):
    for i, ch in enumerate(text):
        node(font, (cx, y_first + pitch * i), ch)
```

- `y_first` = 首字中心 y：`y0 + (框高 − (n−1) × pitch) / 2`
- `pitch` = 字距，一般 25–32 px；字数少的框可拉到 32–43 px 撑满
- **首末字到框边的距离必须相等**

## 4. 断行要按语义

- 每行字数尽量一致（4 字框就 4 字，别出现 5/2/5）
- 在词组边界断，不要在"的 / 和 / 与"这类虚词后断
- 断行写死在数据里，不要交给自动换行——自动换行的断点不可控

```python
box(435, 652, 673, 697, ["特征提取", "分支1"])     # 好
box(435, 652, 673, 697, "特征提取分支1")           # 差：自己折行，位置随机
```

## 5. 中英混排

数字和字母与汉字之间默认会插空隙，看起来像多了个空格：

```latex
\xeCJKsetup{CJKecglue={}}
```

设了之后 `分支1`、`XXX参数测量` 才会紧贴。

## 6. 粗体

- 只有 L1 标题、区块标题条、结论条用粗体
- 正文框一律常规；一排框里混粗体会显得脏
- 必须显式指定 BoldFont，否则 `\bfseries` 报 `Undefined control sequence`
- 汉字紧跟 `\bfseries` 会被当成控制序列名的一部分（xeCJK 下汉字 catcode 为 11），
  写法要留空格：`{\bfseries 研究步骤}`

## 7. 文字与框的比例

经验规则：**框内文字占框宽 60–75% 最舒服**。

- 低于 50% → 太松，缩框或加内容
- 高于 85% → 太挤，降字号（L3→L4）或加宽框

同理，文字块占框高 50–70%；上下留白要对称。

## 8. 行内元素对齐

- 框内文字：水平居中 + 垂直居中，不要左对齐（会出现"参差的右边"）
- 分格框（表格式）：每格独立居中，不要用 `tabular`（列宽难控）
- 竖排标签：水平居中于标签框
- 标题条内文字：居中；如果标题条很宽（>8 cm），也仍然居中，不要左对齐

## 9. 长标题放不下时

优先级：① 缩小字号（L3→L4）② 加宽框 ③ 按语义断成两行。
不要用自动换行，也不要让文字压到框线上。

单选一行超宽时（如"为城市街旁绿地的恢复性提升和交通噪声治理提供科学依据"28 字），
先把框拉满整栏宽度，再考虑降字号——这类结论条通常占满宽度才好看。
