# 06 交付前自检

按顺序过一遍。每一条都能在 10 秒内判断，不要凭"感觉还行"交付。

## A. 版面

- [ ] 整图宽度在 11–13 cm（单栏）或 16–17 cm（双栏），插入正文后字号不小于 6.5 pt
- [ ] 同类框同高；同一列同宽
- [ ] 容器内边距左右相等、**上下相等**
- [ ] 区块间距一致（选一个值，全图统一）
- [ ] 没有元素越出虚线容器边界
- [ ] **每个容器都贴着内容包**：容器底边 − 末元素底边 ≤ 40 单位，且各容器这个差值接近
- [ ] 容器底边不靠"拉高"来凑版面

快速判定法：把图缩到 30% 看整体，**灰块（标题条）应该形成规则的横条阵列**。
如果灰块高低错落，说明行高没统一。

留白也能用代码卡死——把内容包围盒和容器边界成对传进去，超了就报错：

```python
PAD_MAX = 42          # 单位，约 5.8 mm
def fit(name, c_bot, b_bot, tol=PAD_MAX):
    assert b_bot - c_bot <= tol, f"{name} 底部留白 {b_bot-c_bot} > {tol}"

fit("数据治理", 374, 404)
fit("模型推演", 734, 764)     # 超过 42 直接 AssertionError，图不会生成
```

这段放进生成器，比事后看图靠谱——**空一大块是生成阶段就该拦下的错误**。

## B. 对齐

- [ ] 每一列的左边界、右边界各共用一条竖线（不是"差不多"）
- [ ] 竖排标签的首字到框顶、末字到框底距离相等
- [ ] 树形支架的横干端点正好落在首/末子节点中心线上
- [ ] 空心块箭头的轴线与它连接的两个元素中心对齐

搭一段检查代码：把所有关键 x 坐标打印出来，人工看有没有孤值。

```python
for name, x in [("左列左", 156), ("左列右", 217), ("中列左", 313)]:
    print(f"{name}: {x}")
```

## C. 文字

- [ ] 全图字号只有 3–4 级（L1 标题 / L2 区块标题 / L3 正文 / L4 小注）
- [ ] 没有文字压线、越框
- [ ] 多行文本行数与原意一致，没有因为字号偏大而多折一行
- [ ] 中文与数字/英文之间没有多余空隙（`\xeCJKsetup{CJKecglue={}}`）
- [ ] 竖排文字是单字一行，横排窄栏是每行 N 字——不要混用
- [ ] 粗体只出现在标题条和结论条

判定：把图放大到 200%，逐个框看最后一行有没有贴到框底。贴了就说明行距偏大或框高不够。

## D. 箭头与连线

- [ ] 每个空心块箭头：`头长 ≥ 0.5×头宽`、`头宽 ≥ 1.8×轴宽`、`总长 − 头长 ≥ 0.9×头长`
- [ ] 区块间距 76–84，箭头整条落在这条通道里，两端贴住相邻元素
- [ ] 共边标签箭头：轴长 30–34、头长 40–44，尖端距内容区 ≥ 10，不戳进内容框
- [ ] 细实心箭头箭身 ≥ 30；带细箭头的行距 30–38
- [ ] 块箭头宽度与它连接的框宽度协调，一般不超过框宽的 15%
- [ ] 树形支架没有悬空端点
- [ ] 连线只走正交；斜线只出现在扇形发散处
- [ ] 箭头方向与逻辑一致（支持关系 / 递进关系不要画反）

生成器里把比例写成断言，比看图可靠：

```python
def check_arrow(L, sw, hw, hh, name):
    assert hh >= 0.5*hw and hw >= 1.8*sw
    assert L - hh >= 0.9*hh, f"{name}: 头尾太短"

varrow(520, 330, 408)     # 通道 78 → 头长 36 + 箭轴 42，一次通过
```

## E. 风格一致性

- [ ] 灰阶只用令牌表里那 5 档
- [ ] 正文框一律白底；灰底只给标题、分组、侧面
- [ ] 线宽只有 0.55–0.7 pt 与 0.8 pt 两档
- [ ] 圆角只用 10 px（小）与 18–20 px（大）两种
- [ ] 虚线密度一致（`on 1.7pt off 1.3pt`）

对照方法：打开 `assets/examples/03-tech-architecture/fig.pdf` 并排放，**遮住内容只看灰度分布**，
两张图的"黑白比例"应该接近。如果新图明显更黑，说明线太粗或框太密。

## F. 导出

- [ ] `xelatex` 编译无警告（`Overfull \hbox` 也要清零）
- [ ] 字体已嵌入：`pymupdf.open(pdf)[0].get_fonts()` 能看到字体名
- [ ] 版面尺寸正确：`page.rect.width/72*2.54` 得出 cm
- [ ] 交付 `.tex` + `.pdf` + 一张预览 PNG
- [ ] 说明插入方式：`\includegraphics[width=\linewidth]{fig.pdf}` 或按实际尺寸

## 常见返工原因

| 现象 | 多半是 |
|---|---|
| 用户说"太挤" | 内边距 <10 px，或字号没降级 |
| 用户说"不像论文里的图" | 没用灰底标题条 / 线太粗 / 圆角不对 |
| 用户说"歪了" | 某列边界差 3–8 px，或行高不一致 |
| 用户说"箭头怪" | 头长 / 头宽 / 箭轴长没按 `01-style.md` 的四条比例约束取，或箭头尖端戳进了内容框 |
| 用户说"看不清" | 整图太宽导致插入后字号 <6.5 pt，应拆图 |
