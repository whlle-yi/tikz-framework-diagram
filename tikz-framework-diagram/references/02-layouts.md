# 02 版式骨架

五种骨架覆盖绝大多数中文学术框架图。**先选骨架，再填内容**——反过来会陷入无限调位置。

选型速查：

| 要表达的关系 | 选 |
|---|---|
| 一条主线，分阶段推进 | A 单列纵向 |
| 三组信息互相支撑（做什么 / 怎么做 / 用什么方法） | B 三列框架 |
| 系统分几层，层间有数据流 | C 分层架构 |
| 一个主题拆成若干子项，或若干子项汇总 | D 树形分解 |
| 多方案 / 多指标横向比较 | E 矩阵对照 |

---

## A. 单列纵向流程

适合"阶段推进"式技术路线：一条主线，每个阶段下面挂若干并列要素。

```
标题条
┌─────────────────────────────┐
│ 阶段一标题 │  要素 要素 要素   │
└─────────────────────────────┘
        ↓（空心块箭头）
┌─────────────────────────────┐
│ 阶段二标题 │  要素 要素 要素   │
└─────────────────────────────┘
```

**结构参数**
- 主栏宽 11 cm；左侧阶段标题条宽 0.9–1.1 cm（竖排字）
- 阶段框高 = 内容行数 × 45 px + 上下内边距 2×15 px
- 阶段之间用空心块箭头，块高 22–25 px，块宽 40–55 px

**可选装饰**：左侧贯穿几个阶段的大箭头，标注"专业性 / 可控性 / 安全性"这类贯穿维度。
大箭头：轴半宽 15 px，头半宽 30 px，头长 30 px，跨 2–3 个阶段。

**要点**
- 每个阶段内部的要素用树形支架从标题条引线，不要只靠视觉相邻
- 阶段标题条与内容区共用边框（不画两条线）

参考：[`assets/examples/01-top-level-plan`](../assets/examples/01-top-level-plan)

## B. 三列框架

最经典的"研究框架图"：左列研究步骤、中列研究内容、右列研究方法，三列同高。

```
┌────────┬──────────────────────┬────────┐
│ 研究步骤│      XXXXXX 研究      │ 研究方法│   ← 三个灰底标题条
├────────┼──────────────────────┼────────┤
│        │ ┌ 区块1（虚线）──────┐ │        │
│ 步骤1  │ │ 标题条            │ │ 方法1  │
│  ↓     │ │ 子框 子框 子框    │ │  ↓     │
│ 步骤2  │ └──────────────────┘ │ 方法2  │
│  ↓     │ ┌ 区块2（虚线）──────┐ │  ↓     │
│ 步骤3  │ │ ...               │ │ 方法3  │
└────────┴──────────────────────┴────────┘
```

**结构参数**（可直接沿用）
- 总宽 13 cm：左列 1.7 cm、中列 8.6 cm、右列 1.9 cm，列间留 3 mm 空隙
- 每个虚线单元：宽 = 中列宽，高按内容 2.6–3.7 cm
- 单元之间用空心块箭头衔接，箭头居中于中列
- 左/右列的框宽相等，与中列单元的左/右边缘对齐

**要点**
- 三列顶部的标题条**必须等宽等高**，且严丝合缝地骑在各自列的正上方
- 中列的每个单元是一个虚线框，内部第一行是灰底标题条
- 左右列的框通过细箭头指回中列的对应单元（箭头朝内）
- 中列内容多时，单元内用"标题 → 树形支架 → 子框"三层，不要再加第四层

参考：[`assets/examples/02-research-framework`](../assets/examples/02-research-framework)

## C. 分层架构

自上而下分层，每层一个虚线大容器，左侧一个竖排标签 + 一个右向块箭头指进内容区。

```
┌───┬──────────────────────────────────┐
│数 │ ┌胶囊标题┐                        │
│据 │ │  内容区（圆角框内排版）          │
│层 │ └────────┘                        │
└───┴──────────────────────────────────┘
         ↓
┌───┬──────────────────────────────────┐
│模 │  实体  →  实体  →  实体            │
│型 │                                   │
└───┴──────────────────────────────────┘
```

**结构参数**
- 容器宽 13 cm；左侧标签框宽 0.85 cm
- 标签框与内容区之间是一个右向块箭头（箭尾与标签框共边）
- 层高 3.6–4.2 cm；层间留 0.45 cm 放空心块箭头
- 标题可用"胶囊"骑在内容框顶边上（胶囊高 0.8 cm）

**要点**
- 左侧标签框是竖排单字，箭头从框的右边框中部伸出（框线在此断开，见 `03-shapes.md` 第 9 节）
- 层内元素按"输入 → 处理 → 输出"横向排布，用细箭头串联
- 需要表达"两两互为输入"时用双向箭头 ⇔，不要画两条反向箭头

参考：[`assets/examples/03-tech-architecture`](../assets/examples/03-tech-architecture)

## D. 树形分解

一个主题拆成若干子项（1→N），或若干子项汇总成一个结论（N→1），也可以先汇合再分流（N→1→M）。

```
        父
   ┌─────┼─────┐
   子1   子2   子3          ← 横干 + 竖线（正交）
```

```
子1 子2 子3 子4 子5         ← 先汇合
   └──┴──┬──┴──┘
         ↓
    ┌────┼────┐
   孙1  孙2  孙3            ← 再分流
```

**结构参数**
- 横干位置：距父节点底边 12–15 px
- 竖线间距 = 子节点中心距（子框宽 + 间距）
- 二级支架的横干跨距 = 首末孙节点的中心之间

**要点**
- 横干的两端必须**正好落在首/末子节点的中心线**上，差 5 px 就有一根竖线悬空
- 分支线只画到子框的边，不要压进框内
- 三层以上就改用 A 或 C 的版式，别硬叠

## E. 矩阵对照

多方案 × 多指标，或"阶段 × 维度"的二维表格式布局。

```
       指标1   指标2   指标3
方案A   ○       ●       ○
方案B   ●       ○       ●
```

**结构参数**
- 行高统一（45–55 px），列宽按内容分配但**保持整列等宽**
- 表头行用 `#D9D9D9`，其余白底
- 分隔线只画横线，不画竖线（更清爽）

**要点**
- 格内文字超过 2 行时缩字号（降到 L4），不要撑高行
- 需要强调某一列时，只给该列加浅灰底，不要加边框

## 组合使用

真实图常常是组合：三列框架的左列内部是单列流程；分层架构的某一层内部是树形分解。
组合时守住两条：

1. **同一张图只用一套令牌**（字号、灰阶、线宽不因版式变化）
2. **每个子版式独占一个矩形区域**，区域之间用留白或虚线分隔，不要交错
