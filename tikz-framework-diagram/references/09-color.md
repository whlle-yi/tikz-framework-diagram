# 09 彩色方案

`01-style.md` 是单色（灰阶）令牌，适合黑白印刷稿。需要彩色时用本方案：
**几何、字号、间距、线宽全部沿用 01，只替换颜色。**

彩色方案适用于：彩印期刊、学位论文彩页、答辩 PPT、电子版插图。
如果最终要黑白印刷，直接用 01 的灰阶令牌，不要指望"彩色转灰度"能好看。

## 1. 色板

三个强色系 + 一个中性灰。每色系只有两档：**深档做描边与文字，浅档做填充**。

| 色系 | 语义 | 深档（描边/文字） | 浅档（填充） | 深档灰度 |
|---|---|---|---|---|
| 主色 navy | 结构、模型、结论 | `#2A4370` | `#D6E0EE` | 65 |
| 青 teal | 数据、输入、采集 | `#2C736E` | `#D3E7E4` | 93 |
| 暖棕 warm | 应用、输出、落地 | `#B0702F` | `#F4E6D4` | 124 |
| 中性 gray | 第四类 / 辅助说明 | `#8A8A8A` | `#EFEFEF` | 138 |

选色三条硬指标：

1. **深档灰度间隔 ≥ 20**（上表 65 / 93 / 124 / 138，满足）。这是黑白打印时还能区分模块的唯一保障。
2. **浅档明度 ≥ 88%**，保证黑字写在上面有足够对比。
3. **饱和度 ≤ 45%**。超过就发艳，印出来像 PPT 模板。

## 2. 单色令牌 → 彩色令牌

| 单色（01-style） | 彩色（本方案） |
|---|---|
| `#FFFFFF` 正文框 | 白底，描边用本层深档 |
| `#F2F2F2` 侧边列 | 本层浅档 |
| `#D9D9D9` 区块标题条 | 本层浅档 + 深档描边 + 深档文字 |
| `#BFBFBF` 顶层分组 | 本层深档填充 + 白字 |
| `#CBCBCB` 立体侧面 | 浅档再深一档（如 `#B9CBE2`） |
| `#4D4D4D` 线条 | 本层深档 |

注意最后一行：**线条跟着本层颜色走**，而不是统一深灰。这是彩色版和单色版最大的观感差异。

## 3. LaTeX 定义

```latex
\definecolor{mainDeep}{HTML}{2A4370}
\definecolor{mainLight}{HTML}{D6E0EE}
\definecolor{tealDeep}{HTML}{2C736E}
\definecolor{tealLight}{HTML}{D3E7E4}
\definecolor{warmDeep}{HTML}{B0702F}
\definecolor{warmLight}{HTML}{F4E6D4}
\definecolor{grayDeep}{HTML}{8A8A8A}
\definecolor{grayLight}{HTML}{EFEFEF}
```

用命名色而不是十六进制字面量——`#` 在 TeX 里是宏参数符，`draw=#2C736E` 会报
`Illegal parameter number`。全部先 `\definecolor` 再引用。

## 4. 使用规则

1. **一个色系 = 一个语义类别**。同一模块的所有元素（容器、标题、子框、连线）同色。
   不要"每个框一个颜色"。
2. **最多 3 个强色系**。第 4 类用中性灰，不要凑青橙绿紫。
3. **颜色只表达分类，不表达重要性**。重要性用粗细、字号、位置来表达。
4. **文字**：白底用纯黑或本层深档；深底用白。禁止浅色底 + 浅色字。
5. **不用渐变、不用阴影**。填充一律纯色。
6. 相邻两个模块不要用同一色系——否则视觉上会并成一块。

## 5. 从单色改彩色：三步

1. 把 01 的 5 档灰按上表映射成本层深浅两档（先全部设成主色系，确认结构没乱）
2. 按模块分类分配色相：同类模块同色，相邻模块不同色
3. 转灰度看一遍，确认三档灰还能分开（差 <20 就调深档明度）

## 6. 灰度自检

```python
from PIL import Image

def lum(hex6):
    r, g, b = (int(hex6[i:i+2], 16) for i in (1, 3, 5))
    return round(.299*r + .587*g + .114*b)

for name, c in [("navy", "#2A4370"), ("teal", "#2C736E"), ("warm", "#B0702F")]:
    print(name, c, lum(c))

# 或者直接看图
Image.open("preview.png").convert("L").save("preview_gray.png")
```

两张图并排看：彩色的那张里能一眼分出的模块，灰度那张里也必须能分出来。

## 7. 反例

| 做法 | 问题 |
|---|---|
| 全图 6–8 种颜色 | 像 PPT 模板，读者记不住每种颜色的含义 |
| 高饱和红/蓝（S > 60%） | 打印发暗发脏，屏幕上也刺眼 |
| 浅色底配黑字以外的淡色字 | 对比不足，投影时看不清 |
| 用颜色深浅表达"重要性" | 与"分类"混在同一维度，读者无法解码 |
| 每个框单独配色 | 失去分类功能，纯粹变成装饰 |
