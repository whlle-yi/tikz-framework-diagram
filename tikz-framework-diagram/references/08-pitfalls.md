# 08 踩坑清单

按"症状 → 原因 → 修法"排。画完发现不对，先对照这里，再去改代码。

## 单位与尺寸

**1. 整幅图放大 2.54 倍**
用了 `x=0.0352778cm`（那是 1/72 英寸）。应为 `x=0.0138889cm`（1/72 cm）。

**2. 文字全部飞出框外，行距明显偏大**
把屏幕像素值直接填进了 `\fontsize{}{}` 的第二个参数。像素要乘 0.3937 才是 pt。
反例：`\fontsize{8.2}{27.9}` 想表达 27.9px 行距，实际是 27.9pt ≈ 71px。

**3. 空心箭头"只剩个头"**
总高小于头长。例如总高 16、头长 13，箭轴只剩 3px，视觉上就是个倒三角。
约束：**总高 ≥ 头长 + 8**。小连接件的高度要单独定，不要沿用大箭头的比例。

**4. 虚线看起来像描边**
dash pattern 密度不对。目标 4px 实 / 3px 空 → `on 1.6pt off 1.2pt`（×0.3937）。
密度越接近 1:1 越像"扫描出来的旧图"，越细越像现代排版。

## 线条与端点

**5. 框被一条斜线穿过内部**
分段画路径时末段加了 `-- cycle`。`cycle` 回到的是**当前子路径起点**，不是整条 path 的起点。
"左边+顶边 / 箭头 / 右边+底边"这种三段式，末段绝不能 cycle。

**6. 支架有一根竖线悬空**
横干端点没落在子节点中心线上。横干必须用 `首子中心 → 末子中心`，
差 10px 就会有一根线吊在半空。

**7. 相邻框的边叠成一条粗线**
两个相邻元素各有边框、间距只有 6~10px 时，两条线会看起来发黑。
这不是错——原样保留即可；但如果**故意**要让它们共用一条边，就只画一个框。

**8. 分组框的边被内部元素压住**
虚线容器内边距给太小（<10px）时，内部框会压到虚线上。
统一给 12–15px，并且元素宽度按"容器宽 − 2×内边距"算，不要按容器宽算。

## 中文排版

**9. 多行文字最后一行溢出框外**
xeCJK 把 CJK 行距放大约 10%，行数越多累积越明显。
改成逐行独立 node 定位（`04-text.md` 第 2 节），行距固定 30px。

**10. 竖排文字上下不对称**
首字顶到框、末字离框底还有半行。`y_first` 要按
`y0 + (框高 − (n−1)×pitch) / 2` 算，而不是从 `y0` 开始数。

**11. `分支1` 中间多了个空格**
xeCJK 的 CJK-Latin 自动间距。加 `\xeCJKsetup{CJKecglue={}}`。

**12. `\bfseries` 报 Undefined control sequence**
两个原因：① 没指定 BoldFont；② 汉字紧跟 `\bfseries` 被当成控制序列名的一部分
（xeCJK 下汉字 catcode 为 11）。写法要留空格：`{\bfseries 研究步骤}`。

## 流程与工具

**13. 覆盖 PDF 报 `Error 1 (driver return code)` / `PermissionError`**
目标 PDF 正被预览器打开。用 `xelatex -jobname=tmp` 输出新名再改名，
或另存文件名并在交付说明里指明哪个是最新。

**14. 改了 `.tex` 下次生成又被覆盖**
工作流是"改生成器 → 重新生成 → 编译"。所有修改都落在 `.py` 里，`.tex` 是产物。

**15. 越改越乱**
一旦开始逐个手调坐标，就会陷入"改了 A 坏了 B"。
回到层级清单，重算那一块的网格，而不是打补丁。

**16. 对齐既有位图时越量越糊**
那是 `07-align-to-reference.md` 的活：覆盖率阈值、虚线要单独扫、叠色判读都在那里。
本文只管"从零画"。
