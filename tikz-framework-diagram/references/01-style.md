# 01 视觉语言与设计令牌

这套风格的特征：**白底、黑线、灰阶分层、严格正交、留白均匀**。
目标不是"好看"，是"放进论文里像同一家排版做的"。

下面的数值提炼自多张已发表的期刊插图，按 72 px/cm 标定（一张 13 cm 宽的图 ≈ 936 px）。
用像素思考更直观，落到 TikZ 时再换算成 cm / pt。

## 1. 令牌表（直接用，不要重新发明）

### 版面

| 令牌 | 值 | 说明 |
|---|---|---|
| 单栏图宽 | 11–13 cm | 期刊单栏上限约 8.4 cm 时改双栏 |
| 双栏图宽 | 16–17 cm | |
| 图内主栏宽 | 11.0 cm（≈790 px） | 三列框架的中列 |
| 容器内边距（小） | 12–15 | 单排小容器、标签框 |
| 容器内边距（大） | 24–30 | 分层大容器：**上下左右都取这个值，且上下必相等** |
| 同行元素间距 | 6–10 px | 一排方框之间 |
| 行间距（无箭头） | 8–14 px | 上下两排之间 |
| 行间距（带细箭头） | 30–38 px | 细箭头需要看得见的箭身 |
| 区块间距 | 76–84 px | 两个虚线单元之间，通道里放一个空心块箭头 |
| 标签栏到内容区 | ≥ 86 px | 竖排标签框右边界 → 内容区左边界，通道里放共边标签箭头 |

### 字号（全图只有 4 级）

| 级别 | 字号 | 字宽 | 用途 |
|---|---|---|---|
| L1 | 11–12 pt 粗 | 28–30 px | 图的主标题条 |
| L2 | 8.3 pt 粗 | 21 px | 区块标题、左侧竖排标签、结论条 |
| L3 | 8.3 pt 常规 | 21 px | 正文框内容（最常用） |
| L4 | 6.5–6.9 pt | 17 px | 极密图的正文 |

行距 = 字号 × 1.4；多行正文的物理行距约 **30 px**，两行以上必须逐行定位（见 `04-text.md`）。

### 线条

| 元素 | 线宽 |
|---|---|
| 普通框线 | 0.55–0.7 pt |
| 标题条 / 外框 | 0.8 pt |
| 连接线 | 0.55–0.7 pt |
| 虚线分组框 | 0.7 pt，`dash pattern=on 1.7pt off 1.3pt` |
| 点线内框 | 1 pt + `line cap=round`，`on 0.6pt off 1.6pt` |

线条颜色不要用纯黑，`#4D4D4D` 更接近印刷灰线；文字用纯黑。

### 灰阶（只有这 5 档）

| 色值 | 用途 |
|---|---|
| `#FFFFFF` | 所有正文框、内容区 |
| `#F2F2F2` | 侧边列（步骤列 / 方法列）底色 |
| `#D9D9D9` | 区块标题条、结论条 |
| `#BFBFBF` | 最顶层的分组标题（视觉最重） |
| `#CBCBCB` | 立体卡片的侧面 |

规则：**灰只给"标题 / 分组 / 侧面"，正文框永远白底**。灰阶一多就显脏。

> 需要彩色版本时看 [09-color.md](09-color.md)：几何、字号、间距都不变，只把上面这 5 档灰
> 换成"三个色系 + 中性灰"的深浅两档，线条也跟着本层色走。

### 形状

| 令牌 | 值 |
|---|---|
| 小圆角 | 10 px |
| 大圆角 | 18–20 px |
| 胶囊 | 圆角半径 = 高度 / 2 |
| 圆柱椭圆 | `ry ≈ 9 px`（很扁），`rx` 按柱宽 |

### 箭头（三种，按用途取，不要混用）

| 类型 | 尺寸 | 用途 |
|---|---|---|
| 空心块箭头（区块之间） | 轴宽 26–30，头宽 60–66，头长 34–40，箭轴长 34–46 | 层级递进、区块之间 |
| 共边标签箭头（右向） | 轴长 30–34，头长 40–44，头半高 24–26，轴半高 12 | 左侧竖排标签框指向内容区 |
| 细实心箭头 | `Latex[length=1.5mm,width=1.0mm]`，箭身 ≥ 30 | 元素之间的流转 |

**比例硬约束**（四条同时满足，箭头才既不像"尖"也不像"只剩个头"）：

- 头长 ≥ 0.5 × 头宽：头太扁会退化成一根针
- 头宽 ≥ 1.8 × 轴宽：否则箭头和连线的粗细分不开
- 箭轴长（总长 − 头长）≥ 0.9 × 头长：头尾都要有长度
- 箭头尖端距下一个元素 ≥ 10，不得戳进内容框

由此推算版面：**区块间距 ≥ 70**，推荐 76–84（头长 36 + 箭轴 42）；
**标签框右边界到内容区左边界 ≥ 86**（轴长 32 + 头长 42 + 余量 12）。
先在骨架里留出这条通道，再往里放箭头；通道不够时拉开版面，不要压缩箭头。

## 2. 版面规则

### 2.1 三级网格
```
栏（column） → 行（row） → 元素（box）
```
先定栏宽和各自的范围，再定每行的 y 区间，最后在单元格里放框。
所有框的左右边界都必须落在栏的边界上，不允许"差不多齐"。

### 2.2 同类同尺寸
同一排的框同高；同一列的框同宽（文字少时也不缩，靠加留白撑满）。
只有"表格型"框组例外：按内容需要分配宽度，但**行高必须一致**。

### 2.3 对称留白
容器内边距左右相等、上下相等；竖排标签的首末字到框边距离相等。
人的眼睛对"上下差 4 单位"极其敏感，对"左右差 4 单位"不敏感——**优先保证上下对称**。

### 2.3.1 容器必须贴着内容包（硬规则）
**先排内容，再套容器**，容器高度 = 内容包围盒 + 上下内边距。反过来（先定一个"好看的"
容器高度再往里填内容）一定会在底部留出一大块空白，这是最容易被一眼看出来的缺陷。

- 容器底边 − 最后一个元素的底边 **≤ 40 单位**（约 5.5 mm）
- 同一排几个容器的这个差值应当接近（相差 ≤ 15 单位）
- 需要更多内容时加内容或缩窄行距，**不要靠拉高容器**来"平衡版面"

### 2.4 连线只走正交
横平竖直，拐角 90°。斜线只用于"一个父节点发散到一排子节点"（扇形），且必须发自同一点。

### 2.5 层级用视觉权重表达
从上到下：灰底标题条（重）→ 白底正文框（轻）→ 虚线分组（更轻）。
不要用颜色、不要用粗边框，只用灰阶 + 字号。

## 3. 常见跑偏

| 症状 | 原因 | 纠正 |
|---|---|---|
| 一眼看出是 TikZ 默认样式 | 用了默认字号、默认箭头、默认圆角 | 套本文令牌表 |
| 图很"挤" | 内边距 <10 px，或字号没有降级 | 加内边距、把次要文字降到 L4 |
| 层级不清 | 所有框同一灰阶同一字号 | 标题条用 `#D9D9D9` + 粗体，正文白底 |
| 看起来"歪" | 同类元素高度不一致 | 同行强行统一 `minimum height` |
| 线太多太重 | 线宽统一 1pt | 框线 0.7pt、虚线 0.7pt、强调 0.8pt |
| 像流程图软件画的 | 箭头是实心粗箭头 + 直角折线 | 换成空心块箭头 + 正交连线 |
